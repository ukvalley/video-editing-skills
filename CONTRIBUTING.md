# Contributing

Thanks for helping! Good contributions:
- **New skills** (folder in `skills/<name>/` with a `SKILL.md` whose frontmatter has `name` and a `description` that says when to use it).
- **Fixes** to scripts — keep them stdlib + numpy + Pillow (no pip installs required) and give every script a `--help`.
- **Better defaults** for other platforms/languages.

Rules
- Never commit client footage, client names, logos or API keys. Use `Acme` / `<client>` in examples.
- Test a script on a 10-second clip before opening a PR, and describe what you tested.
- One skill or fix per PR.
