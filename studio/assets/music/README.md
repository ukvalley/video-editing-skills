# Music
Background tracks for any project (royalty-free). Name them by mood + BPM, e.g. `upbeat-corporate_110bpm.mp3`.
Music is ducked under the voice automatically.
- `garba_cinematic_128bpm.wav` — original garba/dandiya track (dhol, dandiya, shehnai, tanpura), 128 BPM 12/8, 34 s, drop @ 11.25 s. Built by `toolkit/make_garba_track.py` (markers in the .json).
